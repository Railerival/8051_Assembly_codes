so primary memory has two parts ROM and RAM

**ROM(Read only memory)**
- primary storage
- non-volatile memory(dependance of the component to electricity)
- it is made of ICs
- permanent memory(keeps data when the device is powered off)
- ROM has firmware(which is basically program that runs the computer)
- ROMs are generally not meant to be altered as they have firmware, but there are sub types of ROM where it can re programmed
- it also has equipment programs(I/O programs that can be used to help interact with the equipments ...

```
ROM
├ Non-erasable
│ ├ PROM
│ └ ROM
└ Erasable
  ├ EPROM (erasable by UV rays)
  ├ FLASH (Electrically erasable)
  └ EEPROM (Electrically erasable)
```

**Non - erasable**
ROM(also known as mask-ROM) is already programmed when it leaves the factory while the PROM (programmable ROM) is programmable by the user or the developer

**Erasable**
- `EPROM`: it can be reprogrammed again and again by erasing it completly by UV treatment and then adding the program to it, but it cannot be changed
- `EEPROM` (`E^2PROM`/ Electrically erasable programmable ROM) : same as latter except its electrically erasable and programmable by electricity and is faster erasure(in ms).
- `FLASH ROM` - similar to the latter, except EEPROM can be erased or rewritten bit/byte wise whereas FLASH does it in large units called blocks or sectors

**RAM(Random access memory)**
- aliases : Read/write memory
- primary storage
- volatile memory
- temporary memory
- It is possible to randomly select and use any location of the memory
directly store and retrieve data. 
- It takes same time to any address of the memory as the first
address.

```
RAM
├ SDRAM
├ DRAM
└ SRAM
  └ Cache memory
    ├ L1 cache
    ├ L2 cache
    └ L3 cache
```

`DRAM` : 
- volatile
- must be continually refreshed in order for it to maintain the data. This is done by placing the memory on a refresh circuit that rewrites the data several hundred times per second
- DRAM is made up of memory cells(one transistor and one capacitor)
- used mostly as its cheap and small.
`SDRAM`
- Hybrid of both DRAM and SRAM.
`SRAM`
- volatile
- 6 transistors and no capacitors
- Transistors do not have leakage so can no refresh needed at all when connected to power
- Fewer bits in the same space as DRAM, making the cost per gigabyte much higher.
- used as cache memory need to be fast and small.

```
Secondary memory
├ Magnetically stored
│ ├ HDDs(Hard disc drives)
│ ├ Magnetic tape drive
│ └ Floppy disc
├ Optically stored
│ ├ CD(compact disk/CD-ROM)
│ ├ Write once read many(WORM)
│ └ Erasable optical disc
└ Electronically stored
  ├ SSDs
  └ pen drives
```

**Cache memory**
- Special high speed memory
- To access memories like RAM its very slower compared to the cpu processing speed so cache is used which is near to the cpu and has a quick access time(acts like a buffer b/w cpu and RAM
- used to store programs that are being currently used or executed
- it makes memory access faster
-  cache cant be too big as it will be expensive
- it stores data about frequently used main memory locations

**Registers**
- Small, special memory units built into CPU
- since CPU processes data at extreme speeds it needs a temporary data holding area to quickly store and use instructions and data.
- not part of the main memory, but fastest storage level for immediate access(faster than cache)
- unlike cache they are in-built in the CPU core but the caches are on outiside of the cores but in the same chip.
